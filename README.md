# Pemba Pre-Flight

60-second proprioceptive self-check for expedition humanoids. Himalaya Robotics Hack 2026, Track 3 (Thinking).

## Setup

```bash
uv sync
git clone --depth 1 --filter=blob:none --sparse https://github.com/google-deepmind/mujoco_menagerie.git && cd mujoco_menagerie && git sparse-checkout set unitree_g1
```
